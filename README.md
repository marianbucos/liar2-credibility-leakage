# LIAR2 Credibility Leakage. Detection and Leak-Free Correction (PSA / WSA / LFA)

Speaker **credibility history**, the per-speaker counts of previously rated statements, is a signature feature of the LIAR and LIAR2 fake-news benchmarks. This repository accompanies our reproducibility study showing that, as released, these counts **leak the label** into evaluation, inflating reported performance, and provides corrected, leak-free versions of the data sets.

We compare three count constructions, reproduced with the Fuzzy Deep Hybrid Network (FDHN) across the full ablation and segmentation suite, each averaged over five random seeds:

- **PSA** (Pre-Split Aggregation): the original, leaky construction.
- **WSA** (Within-Split Aggregation): per-split counts with self-exclusion.
- **LFA** (Leak-Free Aggregation): train-only, leave-one-out, the only honest construction.

**Key finding.** On the full model, PSA inflates the Mean metric by $+0.0846 \pm 0.0038$ over LFA; once leakage is removed, credibility history provides no detectable benefit ($-0.0014 \pm 0.0016$). Per-method result tables are in [`results/`](results/).

## Repository structure

```
data/          original and corrected data sets (LIAR, LIAR2, LIAR2-mix; PSA/WSA/LFA variants)
src/           data set-construction scripts (download, mix generation, WSA/LFA/WSA-noSE)
experiments/   ablation/ and segmentation/ FDHN scripts with their .out run logs
results/       per-method result tables (PSA / WSA / LFA) and the original authors' README
```

## Reproduction

1. Build the data sets from `src/` (e.g. `python src/lfa_liar2.py`, `python src/wsa_liar2.py`, `python src/generate_mix_datasets.py`).
2. Run an experiment, passing the variant (`liar2`/`wsa`/`lfa`) and a seed, e.g.
   `python experiments/ablation/1.7.credibility.py lfa 42`.
   Each script appends a `===== SEED N =====` section to its `.out` file.
3. Metrics are averaged over the five seeds {7, 13, 42, 77, 123}.
