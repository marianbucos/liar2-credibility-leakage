# LIAR2 Credibility Leakage. Detection and Leak-Free Correction (PSA / WSA / LFA)

## PSA: Pre-Split Aggregation

Pre-Split Aggregation (PSA) reproduces the credibility counts exactly as released in the original LIAR/LIAR2 files: each speaker's count vector is aggregated over the **entire corpus before** the train/validation/test split. Because the aggregation spans all splits, a validation/test row's count vector includes its own label and is identical to that speaker's training vector, leaking label information into evaluation. The tables below therefore quantify the **inflated, leaky baseline**.

All values are the mean over five random seeds (7, 13, 42, 77, 123).
