# LIAR2 Credibility Leakage. Detection and Leak-Free Correction (PSA / WSA / LFA)

## LFA: Leak-Free Aggregation

Leak-Free Aggregation (LFA) is the **only leak-free construction**: counts are derived exclusively from the **training** labels, the current row's own label is excluded when building its vector (leave-one-out), and speakers unseen in training receive a zero vector. Validation and test rows are scored with frozen train-derived counts, so no evaluation label ever enters a feature. The tables below report the **honest** performance of the credibility features.

All values are the mean over five random seeds (7, 13, 42, 77, 123).
