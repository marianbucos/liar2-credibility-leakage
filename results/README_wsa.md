# LIAR2 Credibility Leakage. Detection and Leak-Free Correction (PSA / WSA / LFA)

## WSA: Within-Split Aggregation

Within-Split Aggregation (WSA) computes the credibility counts **independently within each split**, with the current row's own label excluded from its vector (self-exclusion). This removes the global cross-split leakage of PSA, but the counts are still estimated from the few same-speaker rows inside each evaluation split, making them noisier than train-derived priors. WSA matches LFA up to seed-level noise.

All values are the mean over five random seeds (7, 13, 42, 77, 123).
